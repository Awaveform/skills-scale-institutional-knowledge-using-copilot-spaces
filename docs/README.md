# OctoAcme Project Management Docs

This repository contains the core project management guidance used by OctoAcme. It covers the lifecycle from initiation through execution, planning, delivery, risk management, and retrospectives.

## Process Summary

- Initiation: confirm the business need, stakeholders, success criteria, and go/no-go decision.
- Planning: prioritize scope, estimate work, define milestones, and build a delivery plan.
- Execution & tracking: run standups, monitor progress, manage blockers, and maintain visibility with the team.
- Risk & communication: identify risks, escalate issues, and communicate status to stakeholders.
- Release & deployment: validate quality, prepare release notes, and deploy with rollback readiness.
- Retrospective & improvement: capture learnings and turn them into action items.
